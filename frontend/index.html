Hash / orderedKhởi tạo, truy cập [], find, end, count, contains, insert, emplace, erase, clear, size, empty; duyệt range-for. Map / set có thứ tự duyệt tăng dần.


Algorithmssort, reverse, lower_bound, upper_bound, binary_search, find, count, accumulate, iota, fill, min_element, max_element, swap trên toàn bộ vector / array qua begin(), end(). Bounds trả về chỉ số; có thể trừ begin().


Số / chuỗimin, max, abs, sqrt, pow, floor, ceil, round, gcd, lcm, to_string, stoi, stoll, stod; string: size, empty, substr, find, front, back; kiểm tra / đổi kiểu chữ; khởi tạo string s = {'a','b'}, string s(3,'x').

Con trỏ&x, *p, **pp, tham số và giá trị trả về kiểu con trỏ, dịch con trỏ trong mảng C một chiều, nullptr, new / delete và new[] / delete[].

Lưu ý: Đây là bộ chuyển C++ sang JavaScript chạy offline, không thực sự nạp thư viện C++ hay tương thích gần như toàn bộ LeetCode. Muốn chạy mọi cú pháp C++ tiêu chuẩn cần compiler thật (ví dụ clang/g++). Mô phỏng hỗ trợ mảng con trỏ, ép (void*) và sizeof cơ bản theo mô hình 64-bit LLP64. Nút G++ + mô phỏng biên dịch bằng G++ thật, dùng GDB lấy snapshot theo từng điểm dừng và đưa dữ liệu quan sát được vào sơ đồ RAM. Độ chi tiết phụ thuộc debug symbols và pretty-printer; một số vùng nhớ nội bộ không thể hiện đầy đủ. Giới hạn: đây không phải compiler C++ đầy đủ. Chưa hỗ trợ ListNode / TreeNode, lambda, iterator tổng quát, struct tùy biến, multimap/multiset, bitset và template tự định nghĩa. Số nguyên dùng độ chính xác JavaScript (an toàn tới 2⁵³ − 1). Tối đa 3.000 bước; vector khởi tạo tối đa 10.000 phần tử. Dùng test case nhỏ. Không dùng cho mã không đáng tin cậy.
Trong bộ nhớ, mỗi chiều mảng hiển thị tối đa 64 ô đầu. Dữ liệu dài cuộn ngang hoặc cuộn bên trong thẻ; chỉ số được đánh dấu không làm thay đổi chiều cao thẻ. Giá trị trả về và stdout được hiển thị đầy đủ. Bấm số dòng để đặt điểm dừng. Bấm biểu tượng ghim trên thẻ biến để theo dõi.

G++ thật · GDB Visual Debugger
Biên dịch mã C++ bằng G++ với debug symbols, sau đó dùng GDB để lấy trạng thái thực thi và đưa vào sơ đồ Stack / Heap / con trỏ. Mô phỏng là ảnh chụp các trạng thái GDB quan sát được; một số chi tiết nội bộ của thư viện, biến đã tối ưu hoặc hành vi không xác định có thể không hiển thị đầy đủ. Mã nguồn và dữ liệu stdin sẽ được gửi đến máy chủ C++ Studio để biên dịch và chạy. Không nhập mật khẩu, khóa API hoặc dữ liệu bí mật.
